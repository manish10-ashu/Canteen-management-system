# Canteen Management System

A C++ and Data Structures based project developed as part of our PBL (Project Based Learning).

## About the Project

The Canteen Management System is designed to make the basic operations of a college canteen easier to manage. The system will handle food items, customer orders, prices, availability, and sales records.

The main focus of the project is to implement Data Structures and Algorithms in C++ and understand how they can be used to solve a real-world problem.

## Main Features

* Manage food items and their prices
* Add and remove food items
* Place and manage customer orders
* Check item availability
* Search and sort food items
* Maintain order and sales records
* Simple and easy-to-use interface
